Glance config checks done:

- Widget keys (`type`, `title`, `cache`, `options`, `template`) exist in `customAPIWidget` / shared properties; `url` omitted is allowed (`fetchCustomAPIResponse` returns an empty response).
- Template helpers used exist in v0.8.8: `trimSuffix`, `replaceMatches`, `concat`, `printf`, `index`, `eq`, `not`, `safeURL`, `.Options.StringOr`.
- Glance substitutes `${NAME}` anywhere in the config, so the regex replacement uses `"$1"`, not `"${1}"` (would have been read as env var `1` and failed to load). Checked: no `${...}` in the YAML block.
- Theme switch: Glance sets `data-scheme="light|dark"` on `<html>` (`document.html`), so the widget shows the `/light` or `/dark` badge with `:root[data-scheme=light]`, which follows Glance's theme picker rather than the OS setting.
- All example icon URLs load on favicons.page (domains, `selfhst/jellyfin`, `simple-icons/github`, `dashboard-icons/proxmox`, `devicon/rust`, `twemoji/house`), both `color` and `mono`, both shapes. Subdomain hosts (`www.youtube.com`, `www.reddit.com`, `news.ycombinator.com`, `en.wikipedia.org`) answer 301 to the registrable domain, which then returns 200; `<img>` follows that, so it only costs one extra round trip. An unknown domain returns a generated icon (`X-Icon-Fallback: true`), not an error. `catalogs.json` and `catalogs/{pack}.json`, linked from the README, return 200.
- `html/template` is the engine (so `safeURL` comes from Glance's `globalTemplateFunctions`, merged into the custom-api funcs); the template's `if`/`range`/`with` blocks balance against their `end`s, and the YAML block parses to the keys `type`, `title`, `cache`, `options`, `template` with six links. Not compiled with Go here.

## Notes

- **How to make the preview**: run Glance (`docker run -p 8080:8080 -v ./glance.yml:/app/config/glance.yml glanceapp/glance`), put the YAML from the widget README into a `small` or `full` column, open it, and crop a screenshot of just the widget (the existing previews are cropped to the widget alone; PNG, lowercase `.png`). The dark default theme is fine; a light-theme shot is a nice extra. Save as `widgets/favicon-bookmarks/preview.png`. That run is also the first real render test.
- **Author field**: set to `kriakiku` (the GitHub login of the `gh` session). As author you commit to maintaining the widget and answering its issues.
- **Risk, self-promotion**: the widget exists to use our service. Precedent helps: many widgets wrap one external API (Dashboard Icons and selfh.st are already used via jsDelivr in "Bigger Bookmarks"). The no-key, no-sign-up, privacy and self-hosting points are in the README for the reviewer.
- **Overlap**: "Bigger Bookmarks" (#339, merged 2026-10-27) also does icon bookmarks. Ours differs: icons resolve from the URL with no per-link `icon`, theme-specific badge plates, `mono` style, packs beyond the four Glance prefixes. CONTRIBUTING allows duplicates when "sufficiently different".
- **Not done, possible follow-up**: brand-coloured titles from the `X-Icon-*` palette headers. Glance's in-template `newRequest ... | getResponse` rejects non-JSON bodies (no way to set `skip-json-validation` there), so the headers of an SVG response are only reachable through per-site `subrequests` with `skip-json-validation: true`, which means listing every site twice. Too clumsy for a copy-paste widget; a JSON palette endpoint on favicons.page would make it easy.
- **Built-in widgets tip**: the README also shows `icon: https://favicons.page/color/github.com` and `icon: auto-invert https://favicons.page/mono/github.com` for the native `bookmarks`/`monitor` widgets (for `docker-containers` it is the `glance.icon` label); that needs no PR anywhere. `/mono/` returns a black (`#000000`) mask, which is what Glance's `auto-invert` (`.flat-icon` gets `filter: invert(1)` when the scheme is not light) expects.
