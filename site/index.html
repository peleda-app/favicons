Website icons,
safely.

One request turns any site's icon into a clean, compact SVG. It is sanitized or traced in a sandbox, fitted to its box, and cached, so your users never touch the site.

    safety
    
  
    Built to be attacked.
    
  
    Every byte from a site is hostile until it has been rebuilt by us.
    
  
    
    
    Sandboxed parsing
    HTML, manifests and images are handled in a throw-away seccomp process with no files, network or exec.
    parser exploits · decompression bombs
    
    
    Clean SVG only
    An allowlist writer emits paths and gradients. Scripts, CSS and embedded images cannot be expressed.
    script injection · tracking pixels
    
    
    No SSRF
    Public addresses over https on port 443 only, no links or redirects to raw IPs, and every foreign host vetted before connecting.
    metadata endpoints · internal networks
    
    
    No read receipts
    Per-recipient subdomains collapse to the site. Users' IPs never reach it and are never logged.
    per-recipient tracking
    
    
    Vetted domains
    Blocklists, domain age via RDAP and a filtering DNS resolver. Blocked sites get a warning icon.
    phishing · fresh malware domains
    
    
    Fair under load
    Per-subnet limits and a round-robin queue keep honest clients served during a flood.
    floods · noisy neighbours

    self-host
    
  
    Two containers, no network for the renderer.
    
  
    One docker compose up -d. The API fetches and caches; the renderer decodes untrusted images in seccomp-confined workers with no network, a read-only root and no capabilities. The image is about 7 MB.
    
  
    
    
    docker-compose.yml
    x-hardening: &hardening
  read_only: true
  cap_drop: [ALL]
  security_opt: ["no-new-privileges:true"]
  user: "65534:65534"
  restart: unless-stopped

services:
  api:
    <<: *hardening
    build: .
    image: ghcr.io/peleda-app/favicons:latest
    ports: ["8080:8080"]
    environment:
      FAVICONS_RENDER__SANDBOX: socket
      FAVICONS_RENDER__SOCKET_PATH: /run/favicons/render.sock
      FAVICONS_CACHE__STORAGE: /var/cache/favicons
    volumes:
      - render-socket:/run/favicons
      - cache:/var/cache/favicons
    pids_limit: 256
    mem_limit: 512m
    depends_on: [renderer]

  renderer:
    <<: *hardening
    image: ghcr.io/peleda-app/favicons:latest
    command: ["render-server"]
    network_mode: none
    environment:
      FAVICONS_RENDER__SOCKET_PATH: /run/favicons/render.sock
    volumes:
      - render-socket:/run/favicons
    pids_limit: 32
    mem_limit: 512m
    cpus: 1

volumes:
  render-socket:
  cache:
