Monochrome masks

    
One request, any colour.

    
style=mono returns a black shape on transparency, with all the information in the alpha channel. Use it as a CSS mask and the icon takes whatever colour you give it: brand accent, currentColor, hover states, dark mode. It comes from the site's own mask-icon or monochrome manifest icon when there is one, and is derived from the colour icon otherwise.

API

    
One endpoint. A contract you can rely on.

    
Always 200 with an image unless you opt out, so an <img> tag never breaks. Every fallback says why in headers. Full contract: docs/API.md.

How it works

    
Hostile input, from the first byte to the last.

    
The request path never waits on the network for long, and attacker-controlled bytes are never parsed by the process that holds the network, the cache and the credentials.

    

      
Normalize
Reduce to eTLD+1; reject IPs, localhost and unknown TLDs.

      
Vet
Aliases, blocklists, domain age (RDAP), filtering DNS.

      
Cache
Memory, then disk or S3; 302 to a public bucket.

      
Fair queue
Round-robin per subnet; the heaviest client is evicted first.

      
Sandbox
Fresh seccomp worker per image, page and manifest.

      
Re-encode
Lossless WebP or PNG; nothing passes through.

    

    

      
seccomp sandbox
No files, no sockets, no exec. A forbidden syscall kills the worker. Optional renderer container with no network at all.

      
No SSRF
Public addresses only, ports 80/443, every redirect hop and foreign host checked before connecting.

      
Bomb-proof decoding
Declared dimensions are checked before any pixel is inflated. 1024 px and 32 MiB caps; gzip, zip and svgz refused.

      
No read receipts
Per-recipient subdomains collapse to the registrable domain. Users' IPs never reach the site and are never logged.

      
Filtering DNS
DNS-over-HTTPS to Cloudflare's malware-blocking resolver by default; sinkholed domains get a red warning icon.

      
Survives floods
Load shedding, per-subnet token buckets, negative caching. Honest clients keep getting icons during an attack.

    

  






  

    
Self-host

    
Two containers. No network for the renderer.

    
The api container fetches. The renderer has no network interface, no root, a read-only filesystem and no capabilities.

    

      

        
terminal


# api + isolated renderer, cache on a volume
git clone https://github.com/peleda-app/favicons
cd favicons && docker compose up -d

# verify the sandbox on your kernel: each probe exits 159 (SIGSYS)
for p in fs write net exec; do
  docker run --rm favicons sandbox-selftest $p; echo "$p: $?"
done

[render]

[cache]

[dns]
provider = "cloudflare-security"

[policy]
min_domain_age_days = 30
