Website icons,
safely.

One request turns any site's icon into a clean, compact SVG. It is sanitized or traced in a sandbox, fitted to its box, and cached, so your users never touch the site.

Real responses from a live instance. Take the controls to try it yourself.

api

One endpoint.

No query parameters, one URL per site, always image/svg+xml. The full contract is in docs/API.md.

GET/v1/icon/{color|mono}/{domain}

Behaviour

  • Sources in order: the owner's BIMI logo, the theSVG catalog, the site itself.
  • Subdomains, query strings, a trailing slash or .svg get a cacheable 301 to the registrable domain.
  • Every icon is fitted edge to edge. mono is a single black path for CSS masks.
  • No real icon? You still get 200 with a generated one, and the headers say why.

Headers

  • X-Icon-Provenancebimi, thesvg, site or upstream
  • X-Icon-Vectororiginal, traced or generated
  • X-Icon-Fallback-Reasonqueued, not-found, blocklisted, …
  • X-Icon-Blockedblocklist or dns-filter
  • CDN-Cache-Controlseparate from browser caching
safety

Built to be attacked.

Every byte from a site is hostile until it has been rebuilt by us.

Sandboxed parsing

HTML, manifests and images are handled in a throw-away seccomp process with no files, network or exec.

Clean SVG only

An allowlist writer emits paths and gradients. Scripts, CSS and embedded images cannot be expressed.

No SSRF

Public addresses over https on port 443 only, no links or redirects to raw IPs, and every foreign host vetted before connecting.

No read receipts

Per-recipient subdomains collapse to the site. Users' IPs never reach it and are never logged.

Vetted domains

Blocklists, domain age via RDAP and a filtering DNS resolver. Blocked sites get a warning icon.

Fair under load

Per-subnet limits and a round-robin queue keep honest clients served during a flood.

self-host

Two containers, no network for the renderer.

# api + isolated renderer, ~20 MB scratch image
git clone https://github.com/peleda-app/favicons
cd favicons && docker compose up -d

# check the sandbox on your kernel: each probe exits 159 (SIGSYS)
for p in fs write net exec prctl; do docker run --rm favicons sandbox-selftest $p; done
